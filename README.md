# X-control-panel-extension-for-chrome-
It's a content control layer for X/Twitter. The main things it does: hide promoted posts, suggested follows, topics, Grok-related UI, and Premium upsells. custom feed, dislike button,  It also lets you apply custom CSS and run custom JavaScript on the page, so technically minded users can do almost anything beyond what the built-in toggles offer.

# Visual customization
There's a theming system (with a "cyberpunk" default), accent color control, font size scaling, and a handful of hover effects for tweets. It protects media (images/video) from being affected by theme filters, which is a detail a lot of similar extensions miss.

# Interaction layer
It adds a dislike button with a ratio-based system that tracks dislike data locally. There's also icon replacement for action buttons, a particle burst animation on likes, and rainbow animation on liked posts — small cosmetic touches.

# Utility features
Timed mutes (auto-expire), tweet notifications for specific users, a custom feed slot system, draggable tweet positioning, per-video volume control, and link bypass for t.co redirect URLs.
